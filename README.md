# ALX — AI Team Orchestration Platform

An AI-powered team of specialised agents coordinated by a "Team Lead" orchestrator. Built on Hermes Agent's delegation system with Linear for task tracking, GitHub for code, and AgentMail for communications.

## Architecture

See [ARCHITECTURE.md](./ARCHITECTURE.md) for the full system design.

## Stack

- **Orchestration:** Hermes Agent (delegate_task)
- **Task Tracking:** Linear (ALX team)
- **Code:** GitHub + Claude Code
- **Communications:** AgentMail + WhatsApp
- **Future:** A2A protocol for cross-framework interop
